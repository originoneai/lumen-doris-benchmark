# 公开评测方法参考

本项目独立构造企业、业务事件、物理数仓、题目、判分和产物协议。参考以下基准公开的方法说明。

- 参考 BIRD 的执行结果评测，将 SQL 真正运行的答案与原始经营流水独立汇总的结果比较，并覆盖数据库内容与口径理解。[BIRD](https://bird-bench.github.io/)
- 参考 Spider 2.0 的企业级 SQL 工作流，用多层原始数据、加工逻辑、宽环境和实际业务材料形成端到端任务。[Spider 2.0](https://spider2-sql.github.io/)
- 参考 BIRD-Interact 的多阶段交互任务，将对话连续性及应主动澄清的口径放入独立检查项。[BIRD-Interact](https://bird-interact.github.io/)
- 参考 DABstep 的多步分析，让完成者结合业务规则、数据和可追溯结果提出有证据的判断。[DABstep](https://huggingface.co/datasets/adyen/DABstep)
